# 🎯 Face Recognition Based Automated Attendance System

This project is a **Python-based automated attendance system** that uses **face recognition** to mark student attendance. It captures real-time video from a webcam, detects faces, recognizes them using pre-trained models, and logs attendance details automatically.

---

## 📌 Features

- ✅ Real-time face detection using OpenCV
- ✅ Face recognition with `face_recognition` library
- ✅ Attendance marking with timestamps
- ✅ CSV file generation for attendance logs
- ✅ GUI for ease of use

---

## 🖥️ Technologies Used

- Python
- OpenCV
- face_recognition
- NumPy
- Tkinter
- Pandas
- CSV for storing attendance
